# Grok 4.6 Diskon 50% di Nous Portal: Model Agentic Murah untuk Hermes Agent

Kabar baik buat pengguna Hermes Agent: **Grok 4.6 lagi diskon 50% di Nous Portal** selama seminggu ke depan, hasil kerja sama Nous Research dengan SpaceXAI. Model yang dibuat khusus untuk *long-running agents* ini bisa dipakai langsung di Hermes Agent dengan biaya setengah harga — dan kabarnya subscription token-nya ikut terpotong 50%. Yuk kita bedah kenapa ini menarik buat kamu yang serius main AI agent.

## 💰 Promo: Grok 4.6 Setengah Harga di Nous Portal

Pengumuman disebar lewat akun resmi @NousResearch di X pada 24 Agustus 2026:

> *"Grok 4.6 is 50% off in Nous Portal for the next week, in partnership with @SpaceXAI. Built with a focus on long-running agents and ambitious interactive work, and perfect for use with Hermes agent."*

Beberapa poin penting dari promo ini:

- **Potongan 50% berlaku selama seminggu** (estimasi sampai sekitar 31 Agustus 2026) — ada tenggat, jadi jangan kelamaan mikir.
- **Subscription token ikut diskon** — dikonfirmasi langsung oleh @David_ dari SpaceXAI saat ada yang nanya "apakah token subscription ikut 50%?" jawabannya: *"yes!"*
- **Teknium** (research engineer Nous) menyebut ini salah satu dari *beberapa* diskon model untuk pengguna Hermes — artinya tren harga model agentic makin ramah.
- **Satu akun portal** sudah mencakup Hermes Agent, Inference API, Hermes Cloud, plus akses ke ratusan model lain.

## 🔥 Kenapa Grok 4.6 Cocok untuk Hermes Agent?

Grok 4.6 dirancang untuk **tugas agentik berat**: sesi panjang yang melibatkan banyak tool call, reasoning bertingkat, dan pekerjaan interaktif yang ambisius — persis pola kerja Hermes Agent yang suka menjalankan workflow panjang (riset → tulis → review → publish).

Fitur yang bikin serasi:

- **Sesi panjang tanpa lelah** — cocok untuk agent yang kerja 24/7 seperti bot cron atau multi-agent team.
- **Interaktif** — responsif saat agent butuh klarifikasi atau konfirmasi tindakan.
- **Murah buat skala** — harga 50% off membuat biaya menjalankan banyak bot jadi lebih masuk akal.

## 📊 Konteks: Hermes Agent Makin Mendominasi

Diskon ini datang di saat Hermes Agent mencatat angka gila-gilaan di OpenRouter:

- **1,5 triliun token** diproses hanya dalam awal Agustus 2026 — nyaris menyamai gabungan 49 aplikasi lain yang dilacak OpenRouter.
- **33,1 triliun token all-time** sejak rilis Maret 2026 — juara 1 ranking harian global OpenRouter.
- Memakai **407 model berbeda** dan **40+ tools**, termasuk model besutan sendiri: Hermes 4 70B dan Hermes 4 405B.

Ini sinyal bahwa era **agentic workflow** benar-benar sudah datang: konsumsi token oleh AI agent kini melampaui percakapan manusia. Model yang mumpuni untuk agent = kebutuhan utama, bukan lagi sekadar chat model yang pintar ngobrol.

## ⚡ Cara Manfaatkan Promo Ini (Poin Praktis)

1. **Login ke Nous Portal**, cek daftar model dan cari Grok 4.6 — pastikan harga sudah menunjukkan diskon 50%.
2. **Pasang di Hermes Agent** — pakai model selector (`/model` di CLI atau settings di Desktop) lalu pilih `grok-4.6` (atau nama yang tersedia di endpoint kamu).
3. **Coba untuk tugas panjang** — jalankan riset multi-sumber, generate artikel, atau bot yang harus kerja berjam-jam. Bandingkan hasilnya dengan model default kamu.
4. **Kalau pakai subscription**, konfirmasi dulu bahwa paketmu ikut diskon — karena token subscription juga dipotong 50%.
5. **Catat deadline promo** — kalau cocok, gas sekarang sebelum harga balik normal.
