Website kamu sering error, lemot, atau tiba-tiba "gak bisa diakses"? Ini **5 penyebab paling umum** — dan gimana cara ngatasinnya.

## 1️⃣ Kena Serangan DDoS 🎯

**Gejala:** Website down total pas lagi ramai, atau loading super lambat.
**Solusi:** Pakai proteksi DDoS (Cloudflare / AntiDDoS Shield). Serangan diblockir sebelum sampai server.

## 2️⃣ Server Kehabisan Resource 💾

**Gejala:** RAM/CPU penuh, website sering timeout.
**Solusi:** Upgrade server atau optimalkan website (cache, kompresi gambar).

## 3️⃣ Konfigurasi DNS Salah 🌐

**Gejala:** Website kadang kebuka, kadang error.
**Solusi:** Cek DNS record, pastikan CNAME/A record benar, dan proxy Cloudflare aktif.

## 4️⃣ SSL/Certificate Bermasalah 🔒

**Gejala:** Muncul peringatan "Not Secure" atau koneksi error.
**Solusi:** Aktifkan SSL otomatis (Cloudflare edge certificate — gratis & instan!).

## 5️⃣ Maintenance / Human Error 🛠️

**Gejala:** Website down setelah update atau ubah konfigurasi.
**Solusi:** Selalu backup sebelum perubahan, dan test di staging dulu.
