Mau bikin website/blog tapi bingung pilih teknologi? Tiga nama ini paling sering muncul: **Hugo, Astro, dan Next.js**. Mana yang cocok buat kamu?

## 🏗️ Hugo — Si Cepat dari Go

**Kelebihan:**
- ⚡ **Super cepat** — build ribuan halaman dalam detik (ditulis dalam Go!)
- 🪶 Ringan — output murni HTML statis
- 📚 Tema banyak & matang (etch, book, hextra...)
- 🆓 Gratis & open source

**Kekurangan:**
- Template Go agak unik (kurva belajar)

**Cocok buat:** Blog, dokumentasi, landing page — yang butuh kecepatan & simpel.

## 🚀 Astro — Si Modern yang Ringan

**Kelebihan:**
- ✨ **0 JavaScript default** — halaman super ringan!
- 🧩 Komponen fleksibel (bisa pakai React/Vue kalau perlu)
- 🎨 Developer experience modern

**Kekurangan:**
- Lebih baru — ekosistem belum seluas Hugo

**Cocok buat:** Blog modern, portofolio, website konten yang butuh interaktivitas dikit.

## ⚛️ Next.js — Si Full-Stack

**Kelebihan:**
- 🧠 SSR + API routes — bisa jadi aplikasi web penuh
- 📦 Ekosistem React raksasa
- 🔄 Revalidate — konten dinamis tanpa rebuild manual

**Kekurangan:**
- 🐘 Lebih berat — butuh server/function (gak murni statis)
- ⏱️ Build lebih lama & lebih mahal di-hosting

**Cocok buat:** Aplikasi web (dashboard, toko online, SaaS), bukan sekadar blog.

## 📊 Perbandingan Cepat

| | Hugo | Astro | Next.js |
|---|---|---|---|
| Kecepatan build | ⚡⚡⚡ | ⚡⚡ | ⚡ |
| Berat halaman | Ringan | Paling ringan | Bisa berat |
| Hosting | Statis gratis | Statis gratis | Butuh server |
| Kompleksitas | Rendah | Sedang | Tinggi |
| Best for | Blog/docs | Blog modern | Aplikasi web |

## 🎯 Kesimpulan

- **Blog & docs** → Hugo (paling cepat & hemat)
- **Blog modern + dikit interaktif** → Astro
- **Aplikasi web beneran** → Next.js

**Pro tip:** Mulai dari yang paling simpel (Hugo) — upgrade kalau kebutuhan udah jelas. Jangan over-engineer dari awal! 😄
