Website kamu tiba-tiba **down** pas lagi rame pembeli? Atau loading-nya lemot parah padahal internet lancar? Bisa jadi website kamu lagi **diserang DDoS** — dan ini lebih umum dari yang kamu kira.

## 🤔 Apa itu DDoS?

DDoS (Distributed Denial of Service) = serangan yang membanjiri server dengan jutaan permintaan palsu sampai **server kewalahan dan tumbang**. Efeknya: website kamu **gak bisa diakses** — dan itu artinya **rugi besar** buat bisnis online.

## 🛡️ Cara Standar Melindungi Website

1. **Gunakan Cloudflare** — jaringan global yang menyaring traffic sebelum sampai ke server kamu
2. **Sembunyikan IP server** — pakai Cloudflare Tunnel supaya alamat asli server gak ketahuan
3. **Aktifkan proteksi DDoS** — Cloudflare punya filter otomatis yang memblokir serangan
4. **Pasang SSL** — koneksi aman dan terenkripsi
